# miii.ai

A static personal learning journal for Nur Amirah Mohd Kamil. Open `index.html` in a browser or serve this directory with `python3 -m http.server 8000`.

## Editing
- Content and links: `index.html`
- Layout, colors, and responsiveness: `style.css`
- Menu, roadmap accordions, and resource filters: `app.js`

No backend, analytics, cookies, or third-party integrations are required. Google Fonts are loaded when available; system fallbacks are provided. Deploy the three site files to a static host when authorized; the project has not been published or connected to a domain.
